  1. Open your project → Media page.
  2. Import source media into the Media Pool FIRST (drag the footage folder in). Wait for thumbnails.
  3. File ▸ Import ▸ Timeline ▸ AAF/EDL/XML… pick the .xml. UNcheck "Automatically import source clips into media pool".
